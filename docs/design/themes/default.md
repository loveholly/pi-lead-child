# 主题层：清爽主题（缺省）

本文规定清爽主题下界面长什么样。交互和信息结构的规则见 [`../system/patterns.md`](../system/patterns.md)，这里不重复。

> 状态：初稿（2026-10-26）。所有色值、字号、间距都引用 `packages/components/src/theme/tokens.ts` 的 token 名。第 14 节列出了画布和 token 还没对齐的地方。
> 画布：<https://claude.ai/artifact/CaEmidya9ZrBN83GPdPq88>

## 1. 气质

| 编号 | 原则 | 落到界面上 |
|---|---|---|
| A-1 | 白底，安静 | 页面和卡片都是白底。卡片靠 1px 细边框和页面分开，不靠底色。 |
| A-2 | 一处强调 | 一个区域只有一个实心的强调色元素，通常是主按钮。 |
| A-3 | 颜色只给小面积 | 状态色和浅色调只用在小面积元素上：圆点、图标、色带、气泡、标签、选中的选项。不铺满卡片或整块区域。 |
| A-4 | 紧凑 | 会话卡片的收起态是两到三行。细节和低频操作收起来。 |
| A-5 | 层次靠字重和位置 | 主次靠字号、字重和位置区分，不靠颜色（P6.5）。 |

## 2. 表面

| 编号 | 元素 | token |
|---|---|---|
| S-1 | 页面、会话区、卡片 | `surface`（#FFFFFF） |
| S-2 | 你发的消息气泡、标签、代码块、行内代码、条数小标签 | `surface-muted`（#F2F4F7） |
| S-3 | 表格表头、展开后的详情行、选中的选项行 | `surface-subtle`（#F7F8FA）或 `accent-wash`（#F5F8FF，只用于选中） |
| S-4 | 别人说的话的气泡 | `accent-soft`（#EAF0FF） |

|---|---|---|

| C-2 | 次要文字：说明句、草稿摘要 | `text-strong`（#475467） |
| C-3 | 辅助文字：时间、来源、标签名、说明 | `text-secondary`（#667085） |

### 3.2 强调色

| 编号 | 规则 |
|---|---|
| C-8 | 强调色是 `accent`（#2F6AFF）。实心只用在主按钮和「进行中」的状态点上。 |
| C-9 | 强调色的文字（链接、选中项、剩余时间）用 `accent-strong`（#1E51D6）。 |
| C-10 | 强调色的浅色调 `accent-soft`、`accent-wash` 只用在小面积元素上（A-3）。 |

### 3.3 状态色

系统层把状态分成五类（P7.1）。本主题每类状态由三种颜色组成：状态点（实色）、文字（深色）、浅底（只用于图标的圆底和日历页色带）。

| 编号 | 状态类 | 状态点 | 文字 | 浅底 | 例子 |
|---|---|---|---|---|---|
| C-11 | 等你 | `warning`（#F79009） | `warning-dark`（#B54708） | `warning-soft` | 待审批、待你决定、等你确认、重要的提醒 |
| C-12 | 进行中 | `accent` | `accent-strong` | `accent-soft` | 已排期的提醒、工单在跑、Fairy 在判断 |
| C-13 | 完成 | `success`（#12B76A） | `success-dark`（#087443） | `success-soft`、色带用 `success-border` | 已确认、已回复、已授权、已解决 |
| C-14 | 已结束 | `text-faint` | `text-secondary` | `surface-muted` | 已取消、不回、已在别处处理 |
| C-15 | 失败 | `danger`（#F04438） | `danger-dark`（#D92D20） | `danger-soft` | 失败、已拒绝、「不是我」 |

| 编号 | 规则 |
|---|---|
| C-16 | 红色只用于真正的故障和安全操作（「不是我」、凭证），不用于强调。 |
| C-17 | 一张卡里最多用两种状态色。 |
| C-18 | 不用整片浅色底表达状态，不用卡片左侧的色条，不用实色色带。例外：图块（Tile）强调时（`emphasis: strong`），小标题条用实色底、白字，图块的边框换成同一个色调；普通的图块还是浅色底、有色字（用户 2026-10-27 定，照画布「用同一套积木拼出的卡」）。 |

## 11. 每种通用模式在本主题的样子

### 11.1 事项（P9.5，例如提醒）

- **收起态**：两行，标准密度下高 58。
  - 左边是日历页，宽 56：顶部色带 16 高，写月份；下面是日期，20 号字。
  - 日历页和正文之间是 1.5px 虚线的打孔线，上下各一个直径 10 的半圆缺口。
  - 正文第一行是标题（`card-title`）；第二行是时间和剩余时间，剩余时间用 `accent-strong`。
  - 收起态没有按钮。点整张卡打开浮层。
- **展开态**（浮层）：
  - 日历页加宽到 72。色带和右边标题那一行同高，并且文字居中对齐。日期放大到 30 号字，下面补出星期和时间。
  - 正文下面是常用时刻的 chip 和一个自由输入框。
  - 右下角一行，从左到右：「取消提醒」（默认按钮）、「改到……」（主按钮）。
  - 点「取消提醒」后，这一行原地变成确认行（P5.3）。
- **日历页色带的样子**（浅底配有色字）：
  - 等待：`accent-soft` 配 `accent-strong`。
  - 重要：`warning-soft` 配 `warning-dark`。
  - 已确认：`success-border` 配 `success-dark`，加一个勾；日期用中性色。
  - 已取消：`surface-muted` 配 `text-muted`，日期上画一道斜线，标题加删除线。已结束的卡点了不再打开。

### 11.2 外来消息（P9.3）

- **收起态**：固定高度，标准密度下 160。从上到下：
  1. 头部一行：来源图标、人名（600）、所属组和渠道、时间，右边是状态。
  2. 对方的话，只占一行，显示最新那条，放在别人说话的气泡里（R-5），超长就截断。有多条时，前面加一个「N 条」小标签（`surface-muted`，S-2）。
  3. Fairy 的建议，只占一行：Fairy 标记，加 600 的「Fairy 建议回」，后面跟草稿原文，用 `text-strong`，超长截断。Fairy 还在干活时，这一行改成进度说明，后面加一根细进度条。
  4. 操作栏：上方一条 `border-soft` 分隔线。从左到右：主按钮「发出」，文字按钮「改一下再发」「我自己回」。最右边是信心胶囊：五个 8px 的小方格，加「信心 0.71」。
- **展开态**（浮层）：
  - 头部最右边有收起图标。
  - 消息最多露出 3 条，其余写「更早的 N 条」。
  - Fairy 的结论行下面是草稿全文，放在白底、1px 边框的框里。
  - 五项检查每项一行，写明差在哪里。
  - 操作栏右边多出「稍后」「不回」。
- **改一下再发**：草稿框原地变成输入框，边框变成 `accent`，外面加一圈 `accent-soft` 光晕。
- **对方要求改规则**（2026-10-27，统一消息事件工单 08）：Fairy 的结论下面加一行「对方要求修改 X，没有照做」，用 `note` 字号和 `warning-dark`（C-11），不加按钮。这一行是系统的结论（P8.1），要不要改由用户在和 Fairy 的对话里定。

### 11.3 决定（P9.1）

- 标题用 `card-title`，上面可以加一行来源（`meta`）。
- 选项是单选行，每行高 34：选项名 600，后面是代价说明（`secondary`、`text-secondary`）。选中的行用 `accent-wash` 底；推荐标记是 `accent-soft` 底加 `accent-strong` 字的小标签。
- 自由输入放在选项下面。
- 操作组在分隔线下面，右对齐。

### 11.4 审批（P9.2）

- 头部高 42：琥珀状态点加「待审批」（C-11），请求方名字 600，后面一句说要做什么，右边写等了多久。
- 内容本身：命令放在 `surface-muted` 底、等宽字的框里；要发出的话放在白底、1px 边框的框里；改动对比放在 `surface-subtle` 底的框里，旧的一行加删除线。
- 后果：每行左边一个宽 56 的标签（`text-secondary`），右边是值。
- 操作组右对齐，从左到右：拒绝（文字按钮）、扩大授权（默认按钮）、授权这一次（主按钮）。

### 11.5 结束行（P9.4）

- 一行，高 42。从左到右：
  1. 状态图标（I-5）加状态词，状态词用该状态的深色。
  2. 对象，600。
  3. 一句结果，用 `text-strong`，超长截断。
  4. 时间（`meta`）。
  5. 展开箭头。

### 11.6 注脚（P9.6）

- 在你那条消息的正下方，右对齐，一行。
- 从左到右：安静版的 Fairy 标记（白底、细边框），灰色文字（`text-secondary`）说做了什么，然后是深色文字按钮「撤销」和展开箭头。没有底色，没有边框。
- 展开后，下面用一条细竖线引出几行细节：来自哪里、撤销后会怎样、不是你说的要怎么办。
- 别的凭证做的操作，改成系统信息行（11.9）。只有钥匙图标和「不是我」按钮用红色（C-16）。

### 11.7 缺席占位（P9.7）

- 一行，高 40。1.5px 虚线框，边框用 `danger-line`，圆角 12。
- 框里从左到右：失败状态的图标，加 600 的「没有回答」，后面引用你那句话。右边是「重发」。
- 回复说到一半被打断时，在已经说出的文字后面接一个小的虚线胶囊，边框用 `warning-border`，里面写原因，再加「重发」。

### 11.8 记录块（P9.8）

- 左边一条 1px 的竖线，竖线顶上是安静版的 Fairy 标记。没有底色，没有外框。
- 头部：「Fairy 在后台处理了 N 件事 · 时间」（`meta`，600）。
- 每一行从左到右：
  1. 等宽字写时间。
  2. 一个标签，写来源和处置（`surface-muted` 底，圆角 6；「延后」用 `warning-soft` 底）。
  3. 摘要，用 `message-body`、`text-strong`，关键数字加粗成 `text`。
  4. 系统给了一个操作时（卡的 `action`，例如 Lead 改了常驻偏好、让一条记忆失效以后的「撤销」，2026-10-29）：行尾一个深色文字按钮，样子和注脚（11.6）的「撤销」一样。不用 Button 组件：它比这一行高，会把会话列表撑开。
     - 进行中写「正在撤销…」，做完、新的卡推来之前写「已撤销」，新的卡推来以后按钮消失。
     - 失败时原因写在同一行里，在末尾截断，全文放进锚定浮层。行的高度不变。
     - 带按钮的行不和别的行合成一行。

### 11.9 系统信息行（P9.9）

- 左对齐一行 `meta`、`text-secondary`（2026-10-28 改成左对齐，原来居中）。前面一个 12 的图标，图标占 18 宽，和记录块的 Fairy 标记对在同一条竖线上。
- 永远只占一行。说明太长时在末尾截断；时间写在说明后面，不被截断。全文放进锚定浮层，行尾一个展开箭头。
- 连续失败时，前面放三个叠在一起的小圆点，颜色从深到浅。
- 你在这台设备上连着做的几件事合成一行：「你刚刚…，还有 N 件」，时间写时间段，展开后一件一行（P9.10）。
- 改设置的记录只写变了的那一项，例如「把 GitHub 的写入从「先问我」改成「直接执行」」。

### 11.10 会话里的基础元素

| 元素 | 样子 |

### 11.13 输入框上的状态栏（排队的事）
