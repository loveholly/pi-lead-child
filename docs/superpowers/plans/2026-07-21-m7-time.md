# M7 时间系统 Implementation Plan

> 依据 DESIGN-GATEWAY §4。REQUIRED SUB-SKILL: superpowers:executing-plans。每阶段 TDD + commit。
> 目标：私人助理从"任务执行器"→"生活管家"。验收：「提醒我周五交房租」周五真提醒；「每周一早上汇总本周工单」自动执行。

## 核心设计裁决
- **职责分工**：lead 负责把自然语言时间（"周五前""每周一9点"）转成结构化字段（ISO due_at / 5 段 cron）——LLM 擅长，前提是 lead **知道当前时间与时区**（每轮注入）。scheduler 只做机械的"到点触发"，不碰自然语言。
- **时区**：daemon 本地时区解析，存 UTC ISO；提示词每轮注入当前本地时间+时区名。
- **cron**：用 `cron-parser`（成熟库）算 next_run_at，不自实现。
- **提醒 vs 执行**：`schedules.spawn=0` 仅建单提醒（如交房租，无 child 可执行）；`spawn=1` 到点建单并派 child（如"每周一汇总工单"）。
- **可测性**：scheduler 接受注入的 `now()` provider，测试用固定时间，杜绝时间依赖 flaky。

## Phase A: schema + DAO
- tickets 加列 `due_at`/`remind_at`（ISO UTC，可空），迁移同 M2.1 模式（ALTER 补列）。
- 新表 `schedules`（DESIGN §4.1）：title/brief/cron/workdir/priority/project/spawn/next_run_at/enabled。
- `src/store/schedules.ts`：createSchedule（存 cron，算首个 next_run_at）、listSchedules、setScheduleEnabled、advanceSchedule（重算 next_run_at）、dueSchedules(now)。
- tickets.ts 加 setTicketTime(ticketId, {dueAt?, remindAt?})；listTickets 支持按 remind/due 到期查询（scheduler 用）。
- 测试：schedule CRUD、cron 首次/推进计算（固定 now）、due/remind 到期查询。

## Phase B: scheduler + 时间注入
- `src/pipeline/scheduler.ts`：`createScheduler(db, {now, onSpawnTicket})`，`tick()` 做三件事（DESIGN §4.2）：
  1. `remind_at <= now` 的工单 → inbox（"工单 #N 提醒：…"）→ 现有投递管道；清 remind_at（一次性）。
  2. `due_at <= now` 且未终态且未提醒过逾期 → attention（每单一次，用 activity 去重）。
  3. `schedules.next_run_at <= now && enabled` → 建工单（spawn=1 则回调派 child）→ advanceSchedule。
- daemon 挂 scheduler：60s tick（`PLC_SCHEDULER_MS` 可配），onSpawnTicket 复用 spawn 逻辑。
- **时间注入**：runTurn 的 prompt 前缀加 `（当前时间：<本地 ISO> <时区>）`；每轮都注入（LLM 不知道"今天"）。
- 测试：三条规则各一用例（注入固定 now + 伪造到期数据）。

## Phase C: lead 工具 + 纪律
- 工具：`set_ticket_schedule(ticket_id, due_at?, remind_at?)`、`create_schedule(title, brief, cron, spawn?, workdir?)`、`list_schedules`、`agenda(days?)`（按 due/remind/schedule 汇总"接下来 N 天"）。
- 提示词纪律新增：①时间语义（"周五前""每周""提醒我"）必须落到字段，禁止只写 brief 文本；②"提醒我 X"类非执行任务建单但不 spawn，由 scheduler 履约；③排任务顺序参考 due_at 紧迫度。
- 时间字段解析：lead 用注入的当前时间把自然语言转 ISO/cron，工具参数直接收结构化值（lead 转换）。
- 测试：工具 execute 直调（set/create/list/agenda 落库与渲染）；提示词纪律锚点。

## 验收（真机）
- 「提醒我 2 分钟后 X」→ 2 分钟后 Slack/CLI 收到提醒（快速验证，不等到周五）。
- 「每分钟建一个测试工单」（临时 cron）→ 观察自动建单 + advanceSchedule，验证后删除 schedule。
- agenda 视图正确聚合。
- lead 对「明天下午3点提醒我开会」正确转成 remind_at ISO。

## Self-Review
- 时间注入是地基，先于所有工具（否则 lead 转换自然语言必错）。
- scheduler 与既有 watchdog/inbox 投递管道复用，不新造通知路径。
- now() 可注入保证测试确定性；cron-parser 处理夏令时/月末等边界。
